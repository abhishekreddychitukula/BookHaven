BookHaven Git Command Reference
===============================

1. git init --initial-branch=main
   Initializes the local repository and sets the default branch to main.
2. git config --global user.name
   Checks the configured Git author name.
3. git config --global user.email
   Checks the configured Git author email.
4. git add index.html about.html
   Stages the initial catalog files.
5. git commit -m "Initial BookHaven catalog"
   Creates the initial snapshot commit.
6. git add index.html; git commit -m "Add featured books catalog"
   Stages and commits the Featured Books update.
7. git switch -c feature
   Creates and switches to the feature branch.
8. git add about.html; git commit -m "Add contact and support section"
   Commits the Contact & Support change on feature.
9. git switch main; git merge --no-ff feature -m "Merge feature branch"
   Returns to main and merges feature with an explicit merge commit.
10. git log --oneline --graph --all
    Displays the verified history graph for all branches.
11. git status --short --ignored
    Verifies that debug.log and temp/ are ignored.
12. git add .gitignore; git commit -m "Add Git ignore rules"
    Stages and records the ignore rules.
13. git revert HEAD --no-edit
    Safely creates a new commit that reverses the temporary-file commit.
14. git status --short
    Confirms the worktree is clean and temporary.txt is absent.

Remote preparation (not executed):
git remote add origin https://github.com/abhishekreddychitukula/BookHaven.git
git push -u origin main
git push -u origin feature
